# Повтор асинхронной операции

Основание: Flutter-код и тема; состояние ошибки проверяется widget-тестом с failing repository.

### ELEM: Кнопка повторной загрузки
- role: нативный `FilledButton`; дополнительная роль не нужна
- name: видимая подпись «Повторить» или «Повторить подключение» сохраняется во время загрузки
- event: none — аналитика в проекте не подключена
- test-id: none — элемент находится по роли и видимой подписи
- shared: `AsyncActionButton`, 5 мест использования

### ELEM: Индикатор повторной загрузки
- role: нативный `CircularProgressIndicator` внутри отключённой кнопки
- name: контекст операции остаётся доступен через неизменную подпись кнопки
- event: none — состояние интерфейса, а не отдельное пользовательское действие
- test-id: none — находится по типу индикатора внутри кнопки
- shared: `AsyncActionButton`, 5 мест использования

### ELEM: Уведомление об ошибке
- role: нативный `SnackBar`, показываемый через общий `ScaffoldMessenger`
- name: безопасное пользовательское сообщение без текста серверного исключения
- event: none — аналитика ошибок в проекте не подключена
- test-id: none — находится по роли и тексту сообщения
- shared: `showAppErrorSnackBar`, используется повторными загрузками и завершением тренировки
