# Главная — активная тренировка

### ELEM: кнопка продолжения тренировки
- role: `FilledButton.icon` — Material-кнопка уже передаёт роль в Flutter Semantics
- name: `Продолжить тренировку`
- event: none — в проекте нет tracking plan, analytics SDK или существующей схемы событий
- test-id: none — элемент стабильно находится по роли и доступному имени
- shared: none — изменение локально для карточки тренировки на главном экране

### ELEM: состояние активной тренировки
- role: text — заголовок секции и метка состояния не интерактивны
- name: `Активная Тренировка`; состояние `В процессе`
- event: none — информационные элементы не являются пользовательским действием
- test-id: none — элементы находятся по видимому и семантическому тексту
- shared: none — состояние формируется в `_NextTrainingCard`
