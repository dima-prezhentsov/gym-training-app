# Динамика прогресса

Цель: превратить накопленную историю в понятный обзор регулярности и роста по отдельным упражнениям без сравнения несопоставимых весов.

## Реализация

1. Добавить относительную к текущей дате demo-историю.
2. Ввести `ProgressOverview` и общий калькулятор статистики.
3. Добавить `ProgressRepository`, `InMemoryProgressRepository`, `ServerpodProgressRepository`.
4. Передавать общие schedule/workout instances в overview и progress репозитории.
5. Добавить `ProgressViewModel` с периодом, упражнением, метрикой, loading/error/empty.
6. Заменить третий tab на экран «Прогресс» с внутренними «Обзор / История».
7. Нарисовать график через `CustomPainter`, без новой зависимости.
8. Перезагружать прогресс после сохранения расписания и завершения тренировки.
9. Покрыть калькулятор, репозитории и ключевые состояния экрана тестами.

## Ограничение

Исторический стрик считается относительно текущего расписания. Для неизменяемого исторического результата в будущем потребуется сохранять snapshot запланированных дат.
