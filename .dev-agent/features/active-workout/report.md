# Отчёт: активная тренировка

## Результат

Реализован сквозной локальный сценарий: пользователь запускает тренировочный день, добавляет подходы с повторениями и весом, завершает тренировку и открывает сохранённую запись в истории.

## Реализовано

- Доменные снимки активной и завершённой тренировки, упражнений и подходов.
- In-memory репозиторий истории с сортировкой по дате завершения.
- App-scoped `WorkoutViewModel`: одна активная тренировка, валидация подходов, удаление и безопасное завершение.
- Полноэкранный маршрут `/workout/:dayId` вне нижней навигации.
- Запуск с главного экрана и из карточки расписания.
- Таймер, список упражнений, форма подхода и подтверждение завершения.
- История тренировок и bottom sheet с подробностями каждого упражнения.
- Error-state загрузки расписания и сохранение активной сессии при ошибке записи.

## Проверки

- `dart analyze` — без замечаний.
- `flutter test` — 14/14 сценариев прошли.
- `flutter build web --release` — успешная production web-сборка.
- Мобильная браузерная проверка — viewport 390×844, прямой маршрут и полный happy path без сообщений в консоли.

## Решения и ограничения

- В один момент может существовать одна активная тренировка.
- Выход с экрана сохраняет прогресс только пока живёт приложение.
- Завершение запрещено без единого подхода.
- Нулевой вес разрешён для упражнений с собственным весом.
- Backend, авторизация, постоянное хранилище и аналитика прогресса остаются следующими этапами.
