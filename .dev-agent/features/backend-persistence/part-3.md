# Часть 3 из 4: постоянное расписание

## Контекст

Пользователь аутентифицирован на backend. Эта часть переносит CRUD расписания на PostgreSQL через Serverpod contract.

## Что делает эта часть

1. Добавляет schema/migration расписания, дней и упражнений.
2. Добавляет endpoint только для владельца данных.
3. Генерирует client contract.
4. Добавляет Flutter API repository и mapping.
5. Переключает production bootstrap с in-memory реализации.

## Чего не делает

Не переносит историю тренировок и агрегаты главного экрана.

## Готово, когда

Создание, изменение и удаление дня сохраняются после перезапуска; пользователь не может читать или менять чужое расписание.
