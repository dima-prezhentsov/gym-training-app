# Часть 1 из 4: Serverpod/PostgreSQL-каркас

## Контекст

Flutter Mini App уже реализует локальные сценарии, но не имеет backend. Эта часть добавляет стандартный Serverpod server/client и локальную PostgreSQL-инфраструктуру без переключения пользовательского интерфейса.

## Что делает эта часть

1. Генерирует Serverpod 3.4.x server/client в `backend/`.
2. Удаляет неиспользуемый сгенерированный Flutter sample.
3. Проверяет запуск генератора, анализ и базовые server tests.
4. Документирует локальный запуск PostgreSQL/backend.

## Чего не делает

Не добавляет auth, пользовательские таблицы и не меняет текущие Flutter repositories.

## Готово, когда

Server и client анализируются, базовые тесты проходят, Docker Compose конфигурация валидна, существующее Flutter-приложение не изменило поведение.
