# Часть 2 из 4: Telegram auth

## Контекст

Serverpod-каркас готов. Эта часть создаёт доверенную серверную идентичность из Telegram Mini App `initData` и подключает bootstrap Flutter-клиента.

## Что делает эта часть

1. Добавляет таблицу пользователя и миграцию.
2. Реализует чистый валидатор HMAC, freshness и обязательных полей.
3. Добавляет auth endpoint и серверную сессию.
4. Передаёт raw `initData` из web bridge во Flutter bootstrap.
5. Покрывает security boundaries тестами.

## Чего не делает

Не переносит расписание и историю на сервер.

## Готово, когда

Валидная Telegram-строка создаёт/находит пользователя, поддельная или просроченная отклоняется, bot token отсутствует во Flutter bundle.
