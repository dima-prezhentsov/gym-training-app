# Ревью: отключение вертикальных свайпов Telegram

## Область

Ревью незакоммиченного изменения `lib/telegram/telegram_web_app_web.dart`. В исходном диффе один рукописный файл; сгенерированных файлов, зависимостей и миграций нет.

## Findings

Блокирующих, важных и косметических замечаний по коду нет.

## Покрытие требований

- Telegram Bot API 7.7+ вызывает `disableVerticalSwipes()` после `expand()`.
- Проверка `isVersionAtLeast('7.7')` сохраняет прежнее поведение старых клиентов.
- Ветка без Telegram по-прежнему возвращает browser launch data до вызова Telegram API.
- Новых строк, логирования, аналитики и пользовательских данных изменение не добавляет.

## Автоматические проверки

- `dart analyze` — без замечаний.
- `flutter test` — 7 тестов прошли.
- `flutter build web --release --base-href /gym-training-app/` — сборка успешна.
