# Ревью серверного обзора и недельной ленты

Основание: незакоммиченный diff, локально запущенная web-сборка главного экрана и автоматические тесты. Анимированное состояние проверено widget-тестом; визуально открыт текущий день без тренировки.

## Объём

- База: `origin/main`, коммит `8d1826c`.
- Рукописное изменение: модели overview, два репозитория, DI, три точки обновления UI, главный экран и два test-файла.
- Исключено: generated, lock-файлы и миграции отсутствуют.
- Тестовая база: 7 файлов; 1 новый файл напрямую покрывает серверный overview, widget suite покрывает экран.

## Находки

Блокирующих, важных и nice-замечаний нет.

## Проверки

- Все данные ограничены существующей авторизованной Serverpod-сессией; новый публичный endpoint не добавлен.
- История хранится в UTC на backend и переводится в локальную зону только для группировки и отображения недели.
- Пустое расписание не приводит к null-crash и предлагает переход в раздел расписания.
- Текущий день остаётся различимым без движения; `MediaQuery.disableAnimations` отключает повторение.
- Для today/training добавлен текстовый semantics-канал, поэтому состояние не передаётся только цветом или анимацией.
- Telegram init data, токены и персональные поля не логируются.

## Not done

- Новая версия ещё не опубликована и не проверена внутри мобильного Telegram WebView.
- Визуально не проверялась дата на стыке года; вычисление покрывается стандартной нормализацией `DateTime`, но отдельного теста на Новый год нет.
